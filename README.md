# AndVM - Android 通用内核 GSI 虚拟机

**从 Android 10 到 Android 17，让每一部手机，都有新的可能。**

_**AndVM 是一款 Android 通用内核 GSI 虚拟机，支持在 Android 设备上运行多个版本的 Android 系统，为系统体验、应用测试、开发调试及安全研究提供独立的运行环境。**_

## 主要功能

01. 多版本 Android 系统支持

支持 Android 10 至 Android 17，可运行兼容通用 Android 语义的 ROM，包括：

- AOSP
- LineageOS
- PixelOS
- 其他兼容的 Android GSI / ROM

无需更换手机，即可探索不同版本的 Android 系统。

02. 虚拟机快照与状态恢复

支持保存虚拟机运行现场，方便随时暂停和恢复。

主要功能：

- 暂停虚拟机并保存当前运行状态。
- 下次启动时恢复之前的运行现场。
- 支持回退至已保存的快照状态。
- 方便应用测试、问题复现及系统实验。

与普通数据备份不同，快照还可以保存虚拟机的运行状态。

03. Recovery、Magisk Root 与 OTA

支持通过 Recovery 进行系统级操作：

- 刷入完整 OTA。
- 安装 Magisk Root。
- 刷入系统补丁。
- 安装兼容的第三方组件。
- 检查系统状态及回退。

为 Android 系统探索提供更高的自由度。

04. ADB 直连

支持直接连接虚拟机的 ADB，使用熟悉的 Android 开发调试工作流。

adb connect <IP>:<PORT>

adb devices

可用于：

- 安装与卸载应用。
- 执行 ADB Shell 命令。
- 调试应用。
- 查看系统日志。
- 文件传输。

05. 悬浮窗运行

支持将虚拟机以悬浮窗形式运行在当前应用之上，实现多任务操作，减少应用之间切换带来的中断。

06. 设备映射

支持对九项设备能力进行独立配置，每台虚拟机可以分别设置。

提供三种配置方式：

- 宿主真实： 按需授权，使用手机真实设备及状态。
- 虚拟数据： 使用虚拟设备数据，创建可重复的测试环境。
- 按项禁用： 关闭不需要的设备能力。

涉及 Wi-Fi、蓝牙与基站等映射功能时，宿主模式可能需要相应系统权限。

## 常见问题

AndVM 是什么？

AndVM 是一款 Android 通用内核 GSI 虚拟机，可以在 Android 设备上运行独立的 Android 系统环境。

AndVM 支持哪些 Android 系统和 ROM？

支持 Android 10 至 Android 17，并支持兼容通用 Android 语义的 ROM，例如 AOSP、LineageOS、PixelOS 等。

低版本手机也能运行高版本 Android 吗？

AndVM 提供跨版本虚拟化运行能力，但实际能否运行取决于宿主设备的硬件性能、系统环境及 ROM 兼容性，并非所有设备都能保证正常运行。

快照和普通备份有什么区别？

普通备份主要保存数据，而虚拟机快照还可以保留运行状态。

通过快照，可以暂停虚拟机并在之后恢复，也可以回退到之前保存的状态，类似于 PC 上的虚拟机快照功能。
